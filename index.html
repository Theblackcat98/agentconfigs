PLAIN-TEXT AGENT HARNESS CARGO
NO PACKAGES · NO DAEMONS · READ BEFORE TAKEN

agentconfigs One developer's working setup for coding agents — kept as plain files, read before taken.

01 / Primary Cargo
Skills (`./skills`)

Folders with a SKILL.md and support files (`references/`, `scripts/`), loaded on demand when a task matches the description.

02 / Subagents
Agent Configs (`./agents`)

Focused markdown definitions that give a subagent a scoped role, allowed toolset, and execution mode (read-only vs. write).

03 / Session & Commands
Prompts (`./commands` & `./rules`)

House rules read at the start of a session (`AGENTS.md`) and reusable slash-command prompts triggered on demand.

04 / Guardrails
Hooks (`./hooks`) & Etiquette

Deterministic lifecycle scripts plus a simple rule: this is a vetted personal shelf, not a marketplace. Listing is not a claim of authorship.

05 / Bundles
Plugins (`./plugins`)

Folders that package any mix of the other cargo — several skills, or a skill with a hook and a command — as one takeable unit, described by a `plugin.json` manifest.
