resident skill

design-taste-frontend (tasteskill v2, MIT). Vetted by use, stored by copy.

Take one

Generate the copy command for a skill, then run it in your own project.

cp -r skills/design-taste-frontend ./skills/

What it stores

  • Skills — a folder with a SKILL.md and its support files, loaded on demand.
  • Agent configs — small markdown files that give a subagent a job and a mode.
  • Agent prompts — house rules and command prompts read at the start of a session.

All plain text. Nothing compiles, nothing installs.

How it is stored

  • In this project's own folders, not in any agent config directory.
  • Nothing is installed into an agent harness.
  • Nothing runs in the background.
  • Read before you take.

Who it is for

Developers who run coding agents in any harness and prefer reading a file over installing a package.

A personal rule against npm install is mine, not this project's.

Not a marketplace

I list skills I have used and vetted. Listing is not a claim of authorship, and nothing here is for sale.
