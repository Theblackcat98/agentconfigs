# First-run checklist

Answer these before proposing any change:

- What does this project do, in one sentence?
- Which command runs the tests, and how long do they take?
- Which command lints/formats, and is it enforced in CI?
- Where do the main entry points live?
- Are there generated files that must never be edited by hand?

Keep the answers short. This checklist exists to prevent confident guesses.
