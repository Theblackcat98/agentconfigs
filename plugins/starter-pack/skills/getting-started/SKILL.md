# getting-started

Use this skill when entering a repository for the first time in a session.

## Instructions

1. Read the README and the top-level configuration files (package manifest, lockfile, CI config).
2. Identify the entry points, the test command, and the build/lint commands.
3. Note the branching model from recent git history (trunk-based vs. long-lived branches).
4. Summarise: what this project is, how to run it, how to verify changes.

Read `references/first-run.md` for the checklist of questions to answer.
